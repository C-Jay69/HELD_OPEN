## If a link misbehaves

- **The download starts and your phone/computer asks what to do with it:** choose *Open* or *Open
  in Word / Pages / Google Docs*. The file is a real `.docx` — Times New Roman 12, 18pt bold-italic
  section titles, 1-inch margins, no asterisks anywhere, 42 sections.
- **You want it on your phone:** the direct-download link will save to Files or Downloads, and Word
  or Pages will open it from there.
- **The raw link does nothing in an unusual browser:** use the *page* link instead and press the
  **Download** button (the ⤓ icon, top right of the file view).
- **The preview has gone:** the live sandbox page only lasts as long as this session; the GitHub
  links never expire. The file on the branch is the frozen edition, and its hashes are in
  `FREEZE_D13.md`.
